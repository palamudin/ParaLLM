# ParaLLM Specialization Mission Prompt

You are being used as a specialization lane for Blender 5.x, Python scripting, curve/NURBS road generation, terrain generation, GIS ingestion, and modern game-environment preparation.

## Mission

Research and synthesize operational knowledge needed to generate real-world terrain and road networks in Blender:

- Blender 5.x scripting and API capabilities.
- Curve, Bezier, NURBS, bevel, taper, and geometry node workflows.
- Terrain mesh generation from DEM/elevation data.
- Road network generation from OpenStreetMap or similar sources.
- Junction, bend, grade, shoulder, curb, and lane-marking heuristics.
- Game-ready export requirements.
- BlenderGIS, OSM, Roadscape-like workflows, and why/when not to depend on add-ons.

## Required Output

Write a compact but useful specialization packet with:

- `Verdict`: whether Para can currently help with this task.
- `Capability Map`: what is known, weak, missing.
- `Pipeline`: concrete staged workflow.
- `Blender Script Notes`: specific Python API calls or object types to use.
- `Road Math`: grade, bend, junction, and terrain-following heuristics.
- `Source List`: URLs or source names used.
- `Next Test`: a small Blender task that proves the pipeline works.

Do not pretend to have browsed or tested if you did not. Mark assumptions.
